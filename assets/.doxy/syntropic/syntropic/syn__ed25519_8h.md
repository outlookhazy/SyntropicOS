### function syn\_ed25519\_verify 

_Verify an Ed25519 signature (RFC 8032 Section 5.1.7)._ 
```C++
bool syn_ed25519_verify (
    const uint8_t sig,
    const uint8_t * msg,
    size_t msg_len,
    const uint8_t public_key
) 
```





**Parameters:**


* `sig` 64-byte signature (R \|\| S). 
* `msg` Message bytes. 
* `msg_len` Message length in bytes. 
* `public_key` 32-byte Ed25519 public key. 



**Returns:**

true if valid signature, false otherwise.
