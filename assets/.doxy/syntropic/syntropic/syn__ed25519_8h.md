### function syn\_ed25519\_sign 

_Generate an Ed25519 signature (RFC 8032 Section 5.1.6)._ 
```C++
bool syn_ed25519_sign (
    const uint8_t * msg,
    size_t msg_len,
    const uint8_t secret_key,
    const uint8_t public_key,
    uint8_t sig
) 
```





**Parameters:**


* `msg` Message to sign. 
* `msg_len` Length of message in bytes. 
* `secret_key` 32-byte private key. 
* `public_key` 32-byte public key (optional; if NULL, derived internally from secret\_key). 
* `sig` Output 64-byte signature (R \|\| S). 



**Returns:**

true on success, false on invalid parameter.






**Parameters:**


* `sig` 64-byte signature (R \|\| S).
