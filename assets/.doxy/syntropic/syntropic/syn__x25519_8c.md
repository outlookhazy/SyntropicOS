## Detailed Description


Based on the TweetNaCl approach: 16 × int64\_t limbs (16 bits each). Simpler and more auditable than 10-limb donna at the cost of some speed. The entire scalar multiplication takes ~10M multiplies.


On Cortex-M4 @ 64 MHz this is ~2-4 seconds — acceptable since handshakes only happen every ~2 minutes.

## Public Functions Documentation




### function syn\_x25519 

_X25519 scalar multiplication._ 
```C++
void syn_x25519 (
    uint8_t shared_out,
    const uint8_t scalar,
    const uint8_t point
) 
```



Computes shared = scalar \* point on Curve25519. Callers invoking [**syn\_x25519()**](syn__x25519_8h.md#function-syn_x25519) directly in Diffie-Hellman protocols MUST verify in constant time that shared\_out is not all-zero (RFC 7748 Section 6.1) to reject low-order input points.




**Parameters:**


* `shared_out` Output: 32-byte shared secret. 
* `scalar` 32-byte private scalar (clamped internally per RFC 7748). 
* `point` 32-byte public point (peer's public key).

### function syn\_x25519\_pt 

_Cooperative protothread for sliced X25519 scalar multiplication._ 
```C++
SYN_PT_Status syn_x25519_pt (
    SYN_PT * pt,
    SYN_X25519_Ctx * ctx,
    uint8_t shared_out
) 
```



Executes one Montgomery ladder or field inversion step per slice and yields PT\_MORE via [**PT\_CONTINUE(pt)**](syn__pt_8h.md#define-pt_continue). Automatically wipes `ctx` before completing with PT\_ENDED. Composes with [**PT\_SPAWN\_IF\_NEEDED(pt, task, child, syn\_x25519\_pt(...))**](syn__sched_8h.md#define-pt_spawn_if_needed) for demand-driven yielding.




**Parameters:**


* `pt` Protothread control block. 
* `ctx` Initialized X25519 context. 
* `shared_out` [out] 32-byte output buffer populated on PT\_ENDED. 



**Returns:**

PT\_MORE while in progress, PT\_ENDED on completion, or PT\_EXITED on invalid args.
