    Detailed Description¶

    Implements the OMA LwM2M client specification over CoAP/CoAPS, supporting: * Data formats: Plain Text, Opaque, TLV (Type-Length-Value Content-Format 11542), SenML CBOR (Content-Format 112). * Standard Object & Resource tree routing (/object/instance/resource). * Registration, Registration Update, and Deregistration workflows. * Device Management: Read, Write, Execute, Discover, Observe & Notify (RFC 7641). * Standard Objects: Device (Obj 3), Firmware Update (Obj 5), IPSO Temperature (Obj 3303).
