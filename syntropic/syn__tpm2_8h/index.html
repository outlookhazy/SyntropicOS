    Detailed Description¶

    Implements a zero-heap, deterministic TCG TPM 2.0 command serializer and response parser: * Direct interface over SPI / I2C / LPC TCG FIFO hardware interface (SYN_Transport). * Measured Boot PCR Operations (TPM2_PCR_Read, TPM2_PCR_Extend for SHA-256 / SHA-384). * Hardware Cryptographic Entropy (TPM2_GetRandom). * Hardware Identity & Remote Attestation Quotes (TPM2_Quote). * Tamper-Proof Non-Volatile Storage (TPM2_NV_Read, TPM2_NV_Write). * Power & Self-Test Lifecycle (TPM2_Startup, TPM2_SelfTest).
