    function syn_uds_dtc_report_test_result¶

    Report diagnostic test result for a registered DTC according to ISO 14229-1 state transitions. 

    bool syn_uds_dtc_report_test_result (
    SYN_UDS_Server * server,
    uint32_t dtc,
    bool failed
)

    Diagnostic monitors must invoke this function whenever a periodic or event-driven test completes: * When failed is true (qualified failure): * Sets testFailed (bit 0), testFailedThisOperationCycle (bit 1), pendingDTC (bit 2), confirmedDTC (bit 3), and testFailedSinceLastClear (bit 5). * Clears testNotCompletedSinceLastClear (bit 4) and testNotCompletedThisOperationCycle (bit 6). * Sets Fault Detection Counter (FDC) to +127.

    • When failed is false (qualified pass):
    • Clears testFailed (bit 0), testNotCompletedSinceLastClear (bit 4), and testNotCompletedThisOperationCycle (bit 6).
    • Sets Fault Detection Counter (FDC) to -128.

    Parameters:

    • server Pointer to UDS server instance.
    • dtc 24-bit Diagnostic Trouble Code.
    • failed True if test qualified failed, false if test qualified passed.

    Returns:

    true if DTC found and updated, false otherwise.

    function syn_uds_dtc_start_operation_cycle¶

    Advance server state to a new operation cycle. 

    bool syn_uds_dtc_start_operation_cycle (
    SYN_UDS_Server * server
)

    Must be invoked at ECU ignition ON / startup and upon completion/boundary of each driving or operation cycle: * If a registered DTC completed testing during the previous cycle without any failure (testNotCompletedThisOperationCycle == 0 and testFailedThisOperationCycle == 0), clears pendingDTC (bit 2) per ISO 14229-1 Table 242. * Clears testFailedThisOperationCycle (bit 1) to 0. * Sets testNotCompletedThisOperationCycle (bit 6) to 1.

    Parameters:

    • server Pointer to UDS server instance.

    Returns:

    true on success, false if server is NULL.
